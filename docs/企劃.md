> 這份從 claude.ai 專案「製作遊戲」的《御劍小道士-企劃》搬進 repo（2026-10-23），之後**以 repo 這份為準**。

> 參考：
> - 關卡玩法：FB 廣告《半夜別修仙》那種「滿屏割草、殺一隻漲一點」的形式（原作實際是掛機養成 RPG，我們以廣告形式為主）。
> - 修仙歷程：類似《凡人修仙傳》那種凡人一步步苦修的感覺——靠丹藥、靈草、法寶慢慢累積，境界差一級就很難打。
> - 結構與系統：自家《奧林帕斯小英雄》；程式骨架：自家《旋風小鬥士》。
> 原則：只借類型與感覺；主角、門派、妖怪、法寶、劇情、美術全部自創。不用韓立、原作門派與法寶等設定，也不用《半夜別修仙》的名稱、角色與畫面。神話人物只用民間傳說（鍾馗、哪吒等）。
> 對象：鵝子＋爸爸。

## 〇、一句話
打更人家的孩子被醉道士救下、帶上山，從煉氣一層的小道士開始：每到午夜就提著會說話的燈籠下山斬妖（廣告那種滿屏割草），白天回洞府打坐、種靈草、煉丹、煉法寶；一盞一盞點回鎮魂燈，一步步築基、結丹、御劍升空，最後成為能跟元嬰老怪鬥法的大修士。

## 故事劇情

### 世界設定
- 三百年前，青燈觀祖師用**七盞鎮魂燈**封住了黃泉鬼門，燈分散在七個地方。
- 最近燈一盞接一盞熄滅：子時一到，村裡燈籠全滅、有人失蹤，**連公雞都不啼了**（夜晚好像不會結束）。
- 所以每一關的目標是「**撐到雞啼**」：雞啼代表那一帶的天終於亮了。
- **殺氣為什麼打完就清零**：斬妖得來的殺氣是借來的，天一亮就散；只有修為是自己的。（把「殺一隻漲一點、每關清零」寫進故事裡）

### 角色（全部自創）
| 角色 | 設定 |
|---|---|
| 主角（名字自己取） | 打更人家的孩子，每晚敲鑼報子時。膽子不大但很倔，修煉資質普通，靠一步步苦修 |
| 燈燈 | 會說話的燈籠精（試做畫面裡跟著主角飄的那盞燈），膽小愛碎念，明明自己是妖卻怕鬼；新手教學和洞府吐槽都靠它 |
| 青燈道人 | 師父。愛喝酒、嘴硬心軟、看起來不可靠，其實是隱藏實力的元嬰修士 |
| 沈寒 | 師兄。天才、急躁、看不起慢慢修，後來走捷徑（吞魂火速成）被反派利用；是一路越來越強的宿敵 |
| 藥婆婆 | 坊市賣靈草的老婆婆，教煉丹；其實是隱居的丹道高人 |
| 血河老祖 | 大反派，元嬰魔修。想打開鬼門吞掉百鬼魂火突破化神，在背後指使各地妖王熄燈 |

- **（2026-10-23 改）境界不再靠修為數字，改成「突破條件」**：每一層都有一組條件（累計斬妖、打倒魔王、斬精英、撐到天亮、一夜斬妖、煉丹…），全部達成才能突破；突破可以在戰場上引雷劫，或在洞府靜室打坐。詳見下方「修行：突破條件」。以下修為相關的舊設定僅供參考。
- **修為來源**：關卡斬妖、閉關打坐（掛機）、服用丹藥、奇遇事件。
- **小階段**：修為滿就自動升。
- **大境界突破**：要突破丹藥＋過一個突破試煉：
  - 築基＝**雷劫**：天雷 5～9 道，紅圈預警，在場上躲。
  - 結丹＝**凝丹**：控制四方靈氣匯入丹田的小遊戲（靈氣條保持在金色區，類似小鬥士發射的金色區）。
  - 元嬰＝**心魔關**：打自己的黑影分身，它會用你自己的功法。
- **成功率**＝丹藥品質（下品約 40% → 極品約 90%）＋試煉表現加成＋之前失敗的累積加成。
- **失敗**：扣當前修為約 20%，下次成功率 +15%（可疊）；不會掉境界。
- **境界壓制**：敵人大境界比你高，你的傷害 ×0.5、受傷 ×1.5——越級很難，要靠丹藥法寶補。
- 節奏目標：約 15～20 小時（含掛機）修到元嬰，每個大境界都有水墨過場。

## 三、關卡（廣告形式）

### 1. 一夜＝一場任務
- 8 分鐘一夜，第 4 分鐘中頭目、第 8 分鐘大頭目；撐到雞啼＝過關。節奏分一般／快攻／圍城（參考奧林帕斯）。
- 每關有**推薦境界**；可越級挑戰但會被壓制。

### 2. 操作
- 全畫面拖曳移動（搖桿不顯示），畫面最底 30px 不吃觸控；放開＝站樁，飛劍攻速 +30%。
- 攻擊全自動；丹藥快捷 2 格（點一下服用）。
- 洞府解鎖「自動御劍」後可以真的掛著打（給掛機感）。

### 3. 殺一隻漲一點（本關殺氣）
- 每斬一隻妖，本關攻擊 +0.2%（線性）；頭目 +5%。「戰力」數字一直跳，用萬／億顯示。天亮清零。

### 4. 頓悟三選一（本關有效）
- 吸魂火漲本關「頓悟值」，滿了三選一：讓你帶進來的功法臨時升級、或臨時學一招新的。
- 卡片三級：凡品／靈品（紫）／仙品（金），每張都能選「不要」。
- 精英妖掉「仙人殘魂」卡（鍾馗、哪吒、雷公電母、太上老君、嫦娥、二郎神），本關有效，一關最多兩位。

### 5. 帶進關卡的永久實力
- 境界屬性、本命飛劍等級、攜帶功法（煉氣 3 格 → 元嬰 6 格）、法寶、丹藥、燈燈（靈寵）。

### 6. 失敗
- 本關殺氣與頓悟清零（本來就會清）。
- 本關得到的材料、靈石、修為**打五折**帶回；已有的修為與境界不掉。
- 洞府可買「替身紙人」：關卡中倒下時原地復活一次。

## 六、元嬰鬥法
- **解鎖**：結丹後期開始遇到元嬰老怪頭目；成嬰後開放**鬥法台**。
- **形式**：在天空一對一（有時帶小怪），雙方三層命：**護體靈光（盾）→ 肉身（血）→ 元嬰**。
- **招式**：
  - 本命法寶對撞：兩邊法寶撞上時**拼法力**——狂點畫面，像小鬥士集氣。
  - 瞬移閃身：快速點兩下，留下殘影。
  - 領域大招：全場範圍，紅色預告，要找安全角落。
  - 召喚：魔頭、鬼兵、屍傀。
- **元嬰出竅**：
  - 你的肉身被毀 → 元嬰逃出，操控小元嬰逃 10 秒就保住（算敗退，戰利品少，不掉境界）。
  - 敵人肉身被毀 → 它的元嬰會逃，追上斬殺才算全勝（掉古寶）。
- **對手**：血河老祖（魔道）、陰屍宗主（鬼道）、玄冰妖王（化形大妖）、金甲老怪（體修）、師兄沈寒（宿敵）。
- **雙人鬥法**：同一支手機上下對戰（沿用小鬥士雙人模式）。同一支手機可以有多個修士存檔，雙方各選一個上場；預設開「公平鬥法」把兩邊境界拉平，也可以關掉用真實境界。
