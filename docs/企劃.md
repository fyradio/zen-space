> 狀態：**企劃 v4（2026-10-23）；主角 3D 試做已到 v0.5（含捏臉面板）**，下一步開工 v0.1 關卡手感
> 這份從 claude.ai 專案「製作遊戲」的《御劍小道士-企劃》搬進 repo（2026-10-23），之後**以 repo 這份為準**。

> 參考：
> - 關卡玩法：FB 廣告《半夜別修仙》那種「滿屏割草、殺一隻漲一點」的形式（原作實際是掛機養成 RPG，我們以廣告形式為主）。
> - 修仙歷程：類似《凡人修仙傳》那種凡人一步步苦修的感覺——靠丹藥、靈草、法寶慢慢累積，境界差一級就很難打。
> - 結構與系統：自家《奧林帕斯小英雄》；程式骨架：自家《旋風小鬥士》。
> 原則：只借類型與感覺；主角、門派、妖怪、法寶、劇情、美術全部自創。不用韓立、原作門派與法寶等設定，也不用《半夜別修仙》的名稱、角色與畫面。神話人物只用民間傳說（鍾馗、哪吒等）。
> 對象：鵝子＋爸爸。

## 〇、一句話
打更人家的孩子被醉道士救下、帶上山，從煉氣一層的小道士開始：每到午夜就提著會說話的燈籠下山斬妖（廣告那種滿屏割草），白天回洞府打坐、種靈草、煉丹、煉法寶；一盞一盞點回鎮魂燈，一步步築基、結丹、御劍升空，最後成為能跟元嬰老怪鬥法的大修士。

## 故事劇情

### 世界設定
- 三百年前，青燈觀祖師用**七盞鎮魂燈**封住了黃泉鬼門，燈分散在七個地方。
- 最近燈一盞接一盞熄滅：子時一到，村裡燈籠全滅、有人失蹤，**連公雞都不啼了**（夜晚好像不會結束）。
- 所以每一關的目標是「**撐到雞啼**」：雞啼代表那一帶的天終於亮了。
- **殺氣為什麼打完就清零**：斬妖得來的殺氣是借來的，天一亮就散；只有修為是自己的。（把「殺一隻漲一點、每關清零」寫進故事裡）

### 角色（全部自創）
| 角色 | 設定 |
|---|---|
| 主角（名字自己取） | 打更人家的孩子，每晚敲鑼報子時。膽子不大但很倔，修煉資質普通，靠一步步苦修 |
| 燈燈 | 會說話的燈籠精（試做畫面裡跟著主角飄的那盞燈），膽小愛碎念，明明自己是妖卻怕鬼；新手教學和洞府吐槽都靠它 |
| 青燈道人 | 師父。愛喝酒、嘴硬心軟、看起來不可靠，其實是隱藏實力的元嬰修士 |
| 沈寒 | 師兄。天才、急躁、看不起慢慢修，後來走捷徑（吞魂火速成）被反派利用；是一路越來越強的宿敵 |
| 藥婆婆 | 坊市賣靈草的老婆婆，教煉丹；其實是隱居的丹道高人 |
| 血河老祖 | 大反派，元嬰魔修。想打開鬼門吞掉百鬼魂火突破化神，在背後指使各地妖王熄燈 |

## 二、修仙歷程（永久境界）

| 大境界 | 小階段 | 解鎖 | 章節 |
|---|---|---|---|
| 煉氣 | 1～9 層 | 飛劍、符籙、藥園 | 第 1～3 章 |
| 築基 | 初／中／後期 | 第二件法寶、藥園擴建、煉器 | 第 3～5 章 |
| 結丹 | 初／中／後期 | **御劍飛行（天空篇）**、本命法寶 | 第 6～8 章 |
| 元嬰 | 初／中／後期 | **元嬰出竅、瞬移、元嬰鬥法、鬥法台** | 第 9～10 章 |
| 化神 | （之後擴充） | | |

- **修為來源**：關卡斬妖、閉關打坐（掛機）、服用丹藥、奇遇事件。
- **小階段**：修為滿就自動升。
- **大境界突破**：要突破丹藥＋過一個突破試煉：
  - 築基＝**雷劫**：天雷 5～9 道，紅圈預警，在場上躲。
  - 結丹＝**凝丹**：控制四方靈氣匯入丹田的小遊戲（靈氣條保持在金色區，類似小鬥士發射的金色區）。
  - 元嬰＝**心魔關**：打自己的黑影分身，它會用你自己的功法。
- **成功率**＝丹藥品質（下品約 40% → 極品約 90%）＋試煉表現加成＋之前失敗的累積加成。
- **失敗**：扣當前修為約 20%，下次成功率 +15%（可疊）；不會掉境界。
- **境界壓制**：敵人大境界比你高，你的傷害 ×0.5、受傷 ×1.5——越級很難，要靠丹藥法寶補。
- 節奏目標：約 15～20 小時（含掛機）修到元嬰，每個大境界都有水墨過場。

## 三、關卡（廣告形式）

### 1. 一夜＝一場任務
- 8 分鐘一夜，第 4 分鐘中頭目、第 8 分鐘大頭目；撐到雞啼＝過關。節奏分一般／快攻／圍城（參考奧林帕斯）。
- 每關有**推薦境界**；可越級挑戰但會被壓制。

### 2. 操作
- 全畫面拖曳移動（搖桿不顯示），畫面最底 30px 不吃觸控；放開＝站樁，飛劍攻速 +30%。
- 攻擊全自動；丹藥快捷 2 格（點一下服用）。
- 洞府解鎖「自動御劍」後可以真的掛著打（給掛機感）。

### 3. 殺一隻漲一點（本關殺氣）
- 每斬一隻妖，本關攻擊 +0.2%（線性）；頭目 +5%。「戰力」數字一直跳，用萬／億顯示。天亮清零。

### 4. 頓悟三選一（本關有效）
- 吸魂火漲本關「頓悟值」，滿了三選一：讓你帶進來的功法臨時升級、或臨時學一招新的。
- 卡片三級：凡品／靈品（紫）／仙品（金），每張都能選「不要」。
- 精英妖掉「仙人殘魂」卡（鍾馗、哪吒、雷公電母、太上老君、嫦娥、二郎神），本關有效，一關最多兩位。

### 5. 帶進關卡的永久實力
- 境界屬性、本命飛劍等級、攜帶功法（煉氣 3 格 → 元嬰 6 格）、法寶、丹藥、燈燈（靈寵）。

### 6. 失敗
- 本關殺氣與頓悟清零（本來就會清）。
- 本關得到的材料、靈石、修為**打五折**帶回；已有的修為與境界不掉。
- 洞府可買「替身紙人」：關卡中倒下時原地復活一次。

## 六、元嬰鬥法
- **解鎖**：結丹後期開始遇到元嬰老怪頭目；成嬰後開放**鬥法台**。
- **形式**：在天空一對一（有時帶小怪），雙方三層命：**護體靈光（盾）→ 肉身（血）→ 元嬰**。
- **招式**：
  - 本命法寶對撞：兩邊法寶撞上時**拼法力**——狂點畫面，像小鬥士集氣。
  - 瞬移閃身：快速點兩下，留下殘影。
  - 領域大招：全場範圍，紅色預告，要找安全角落。
  - 召喚：魔頭、鬼兵、屍傀。
- **元嬰出竅**：
  - 你的肉身被毀 → 元嬰逃出，操控小元嬰逃 10 秒就保住（算敗退，戰利品少，不掉境界）。
  - 敵人肉身被毀 → 它的元嬰會逃，追上斬殺才算全勝（掉古寶）。
- **對手**：血河老祖（魔道）、陰屍宗主（鬼道）、玄冰妖王（化形大妖）、金甲老怪（體修）、師兄沈寒（宿敵）。
- **雙人鬥法**：同一支手機上下對戰（沿用小鬥士雙人模式）。同一支手機可以有多個修士存檔，雙方各選一個上場；預設開「公平鬥法」把兩邊境界拉平，也可以關掉用真實境界。

## 十、畫面與技術
- Three.js r128（cdnjs，跟小鬥士同一版），單檔 HTML，直向。
- **主角試做的做法**（之後直接沿用；現況與細節見 `docs/主角造型.md`）：
  - 全部程式產生：車床曲面做上衣與下襬、球面雕刻做頭、整片髮殼＋髮束做頭髮、髮髻＋金冠＋玉簪、背上斜背長劍。
  - 柔光立體著色（PBR＋ACES 色調），不描邊；五官畫在臉部貼圖上並用頂點位移雕出立體。
  - **會動的布料**：後髮、髮帶、腰間絲絛、劍穗、玉佩流蘇用繩索模擬；廣袖用小塊布料模擬垂墜；下襬依移動方向擺動，御劍時往後飄。
  - 三套道袍配色：月白青衫、玄墨朱紋、絳紅金邊。
  - 燈燈（燈籠精）跟在右肩後方，帶暖色點光源；場景有冷月、霧、墓碑枯樹、鬼火。
  - **捏臉系統**：參數 `F` → 重畫臉貼圖＋重算頭型；可複製／貼上設定。
- **字體**：標題字體只取「午夜來斬妖」五個字做子集內嵌（每種約 2～6 KB），UI 用霞鶩文楷 TC 子集內嵌；全部 OFL 授權、離線可用。字體檔從 GitHub `google/fonts` 用 git 稀疏下載（raw 網址會被擋）。
- 妖怪同種共用 InstancedMesh；場上上限先抓 220 隻，實測再調。
- 防過熱一開始就做：預錄音樂、手機降解析度、省電／流暢模式、遠處不畫陰影。
- 存檔單一 localStorage key（含版本、深度合併預設值），支援多個修士存檔；藥園與閉關用真實時間戳記。發佈沿用 game-pwa-release（repo 已建、Pages 已開）。
- 本機測試：Three.js 也用 git 下載 r128 build，Playwright 手機尺寸截圖（軟體繪圖約 2～5 fps，只看畫面不看效能）。

## 十一、數值初稿（之後機器人調）
- 煉氣一層：生命 100、攻擊 10、移速約 6 格/秒；每小層 +10%，每大境界 ×3。
- 本關殺氣：攻擊 ×(1 + 0.002 × 擊殺數)。
- 妖怪生命：章節基礎 × (1 + 0.25 × 分鐘)^1.5。
- 境界壓制：差一個大境界，傷害 ×0.5、受傷 ×1.5。
- 突破成功率：丹藥 40%～90%＋試煉表現最多 +15%＋每次失敗 +15%；失敗扣當前修為 20%。
- 一關修為約等於閉關 30～60 分鐘的量（打關卡比掛機快，但掛機也有進度）。

### v0.1 實作現況（2026-10-23，`src/game.src.html` → `game.html`，已依使用者試玩回饋改過三輪）
- 主角用共用的 `src/hero_core.js`，所以就是捏臉頁捏的那張臉、那套身形（GitHub Pages 同網域會共用存檔；Artifact 各自一份）。
- **一夜 3 分鐘**（使用者：8 分鐘太長）：難度曲線是原本 8 分鐘的曲線壓進 3 分鐘；40% 出精英「大燈籠鬼」，67% 燈籠大王登場，最後 10% 天色漸亮，時間到雞啼＝過關。
- 場景：白石村夜晚，石板廣場＋古井、一圈白牆黑瓦的屋子、熄掉的燈籠、枯樹、地霧。
- **視角**（右上「視」或 V 鍵，會記住）：俯視、斜視、追尾（在主角背後跟著轉）；拖曳方向依鏡頭換算。
- 操作：全畫面浮動搖桿（不顯示），最底 30px 不吃觸控。電腦可用 WASD／方向鍵，Esc 暫停。
- **走路 vs 站樁**（使用者：走路反而會撞到妖受傷，沒意義）：
  - 走路＝每走 2.4 公尺放一圈「劍罡」（傷害＋擊退）、被撞只受一半傷害並把妖彈開、吸魂範圍 ×1.5。
  - 站樁＝施法姿勢，出劍 +30%。
- 飛劍：開場 2 把、穿透 1，每 0.62 秒一輪，追蹤最近的妖；只鎖定畫面中間、5 公尺內的妖（天眼最多 8 公尺）。魔王例外：10 公尺內就會打，而且每輪一半的劍、第一道雷、符籙都優先打魔王（直向手機畫面左右只有約 4 公尺寬）。
- 小妖造型與招式（全部 3D 建模、面向主角、腳下影子、用自身顏色微發光）：
  - 遊魂：白衣破擺、長黑髮遮臉露紅眼、寬袖伸手。普通近戰。
  - 紙人：紅紙衣金邊、白臉腮紅、黑紙帽、竹籤腳。**衝刺**：停下抖動、地上畫紅線，然後直線衝過去。
  - 跳跳殭屍：藍官服金邊、官帽紅珠孔雀翎、臉貼黃符、雙手平舉長指甲、辮子。**跳撲**：在主角腳下畫紅圈，0.7 秒後跳過去落地傷害。
  - 燈籠鬼：竹骨燈籠、大眼吐舌。**遠程**：保持距離、膨脹發亮後吐火球（精英一次吐 5 顆扇形）。
- 回春丹：第 67、167、267、367… 隻擊殺掉一個紅葫蘆，撿到回 20% 生命。
- 頓悟三選一（凡品／靈品紫／仙品金，可選「不要」）。使用者嫌「只有劍越來越多」，所以：學會的招式少於 4 個時，第一張卡一定是還沒學過的新招；新招抽中機率加倍；飛劍最多 6 把。
  - 屬性卡：分光劍、劍氣凝鋒、疾風出劍、穿雲、天眼、踏雲步、攝魂、回春。
  - 招式卡：劍陣（飛劍繞身）、雷火符（看得到的黃符「敕令」飛出去爆炸）、燈燈助陣（燈籠吐火球）、引雷訣（每 4 秒天雷劈下）、金鐘罩（金色大鐘擋一次傷害並震開周圍）。
- 殺氣：每斬一隻 +0.2%×（480/一夜秒數×0.75），精英／頭目各 +5%。
- 頭目：血量＝登場時玩家戰力約 30 秒的量（使用者：魔王比一把小怪還弱），單次傷害最多扣 4%；半血後**狂暴**：喊話、紅圈火球更快、每 4.5 秒放一圈 14 顆火球。精英血量＝戰力約 12 秒。
